# Parkrun from IMAP

Local parkrun records for Home Assistant, maintained through imported result and
volunteering emails or manual actions. No parkrun server access or credentials.

Features: lifetime PB and age grade, calendar-year and rolling-year records,
running/volunteering/combined venue lists, persisted local data, and multiple runners.

Use HACS as a custom integration repository using this repository.
See [README.md](README.md) for installation, IMAP/iCloud settings, search filters,
a complete import-and-move automation, testing and manual setup.

Version 3 removes the previous API, scraping, refresh, next-event and cancellation
features. See the upgrade instructions before replacing an older installation.
